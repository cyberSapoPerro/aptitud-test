# Aptitud test

A simple web application to simulate aptitude tests and practice solving questions in a timed environment.


## Requirements

- Bun

## Usage

Clone this repo and run

```bash
git clone <repository-url>
cd aptitud-test
```

Install the dependencies:

```bash
bun install
```

And start the development server:

```bash
bun run dev
```

Open the local URL displayed in the terminal to access the application.
