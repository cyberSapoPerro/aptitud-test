# Test de aptitud

Aplicación para practicar y evaluar distintas habilidades relacionadas con la aptitud mental en un entorno cronometrado.

## ¿Qué encontrarás en la prueba?

La evaluación está dividida en cuatro secciones:

1. **Razonamiento:** preguntas basadas en relaciones y comparaciones.
2. **Rapidez numérica:** ejercicios breves de identificación de números.
3. **Rapidez perceptiva:** comparación rápida de grupos de letras y caracteres.
4. **Significado de palabras:** preguntas sobre relaciones entre palabras en español.

Las preguntas aparecen en un orden diferente cada vez que se inicia una evaluación. Cada sección tiene su propio tiempo límite.

## Cómo realizar la evaluación

1. Inicia la aplicación.
2. Pulsa **Comenzar evaluación**.
3. Lee la pregunta y selecciona una opción.
4. Pulsa **Siguiente pregunta** para continuar.
5. Completa las cuatro secciones.

Cuando eliges una respuesta, la aplicación muestra cuál era la opción correcta. Después puedes continuar con la siguiente pregunta.

## Resultados

Al finalizar verás:

- La puntuación total.
- La puntuación obtenida en cada sección.
- El número de respuestas correctas.

También puedes pulsar **Descargar resultados** para guardar un archivo con el detalle de cada pregunta. Ese archivo incluye:

- El número de la pregunta.
- La sección a la que pertenece.
- Si la respuesta fue correcta o incorrecta.
- El tiempo utilizado para responder.

Las preguntas que no se hayan respondido quedarán registradas como incorrectas y sin tiempo de respuesta.

## Cómo iniciar la aplicación

Necesitas tener instalado [Bun](https://bun.sh/).

Después, ejecuta:

```bash
git clone https://github.com/cyberSapoPerro/aptitud-test
cd aptitud-test
bun install
bun run dev
```

Abre en el navegador la dirección que aparecerá en la terminal.
